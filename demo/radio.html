Attribute

The Accesserty UI Kit radio attributes:
Name Description
value On the group: requested selection. On an option: its submission value. Use unique explicit option values; an empty value is allowed.
checked Option-only initial selection marker. Later explicit changes update selection; label changes do not replay initial markers. Use the group's value property for controlled state.
disabled Disable the group or an individual option. Disabled fieldsets also prevent interaction and submission without discarding selection.
direction horizontal / vertical
label Fallback accessible name for <au-radio-group>. Also supported on child radio items as visible option text.
aria-label Accessible name for the radio group.
aria-labelledby IDs of visible group labels in the containing document or shadow root.
aria-describedbyIDs of group instructions or error messages.
nameNative form submission key. Unnamed groups submit no entry.
requiredRequire selection using native radio validation when enabled options exist. An empty or entirely disabled option list has no validation anchor.

Delivery method (required)

Choose one delivery method. Reset clears your selection.

Standard delivery Express delivery Pickup (unavailable)

This demo does not send data. Tab enters the selected option (or the first enabled option). Arrow keys move and select, skipping disabled options and wrapping; Space selects the focused option. This is a standalone radio group, not the different radio-in-toolbar keyboard pattern.

Properties

JavaScript properties on <au-radio-group>:
Property Type Description
value string | null (getter + setter) Select an option by value; null clears selection. Returns null if no option matches. Unmatched requests are retained for options inserted later. Property writes do not reflect the value attribute or emit change.
disabled boolean (getter + setter) Get or set the disabled state of the whole group.
name / requiredstring / booleanWritable native form key and required constraint.
 
const group = document.querySelector('au-radio-group');
group.value = 'express';
console.log(group.value);
group.disabled = true;

focus() focuses the current enabled tab stop. checkValidity() and reportValidity() expose native form validation. Reset silently restores the selection captured when the first options are rendered; later value writes do not change that baseline.

Option nodes and keyboard focus survive label, language and value updates. When a focused option is removed or disabled, focus moves to an enabled option or the group fallback. Option labels are plain text; do not place links or buttons inside an option.

Events

Events dispatched by <au-radio-group>:
Event Detail Description
change { value: string } One notification per user selection. Bubbles and is composed. Programmatic value changes, reset and restoration are silent.
inputNative eventFormData is synchronized before the native composed input event reaches the consumer.
 
document.querySelector('au-radio-group').addEventListener('change', (e) => {
  console.log('Selected:', e.detail.value);
});

Framework and accessibility boundaries

Bind the group value and handle change.detail.value to update your model. Vue/Nuxt use explicit :value and @change; Angular form directives still need a value accessor. Register the component only on the client. The Next/Nuxt/Angular fixtures verify host SSR and hydration, not server-rendered shadow controls or operation without JavaScript.

Provide a visible group name and meaningful option text. Native element-reference labeling is used where supported; older engines use a plain-text fallback, so rich labels may need an explicit localized aria-label. Test your own themes, error flow and assistive technologies; the component is not a WCAG conformance guarantee.
