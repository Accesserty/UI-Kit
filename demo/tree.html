Accesserty UI Kit Tree

How to use

  1. Copy file (tree.js or accesserty-ui-kit.js or accesserty-ui-kit.min.js)
  2. Add the JavaScript file to HTML using the <script src="" defer> tag
  3. Use the <au-tree> tag

Ensure to replace 'your-path' with the actual path to your JavaScript file. Also, make sure the path and filenames are correct to avoid loading errors.

Custom Toggle Label

Customize the aria-label of toggle buttons with an attribute template or JavaScript function.

<au-tree aria-label="Project files" data-text-node="Node" data-text-toggle="Expand or collapse {label}"></au-tree> const customLabelTree = document.getElementById('tree-custom-label'); customLabelTree.toggleLabel = (node) => { return `Expand or collapse ${node.label}`; };

Properties

JavaScript properties on <au-tree>:
Property Type Description
data Array of node objects Set the tree data as a JavaScript array. Each node can have label (string), children (array, optional), and disabled (boolean, optional). Use sibling-unique id values for updates that preserve focus and state. Without IDs, the same object references are needed. Disabled branches cannot be checked by users or ancestor cascades, but remain navigable and expandable. Labels render as text. 
document.querySelector('au-tree').data = [
  { id: 'parent', label: 'Parent', children: [
    { id: 'first', label: 'Child 1' },
    { id: 'second', label: 'Child 2', disabled: true }
  ]},
  { label: 'Leaf node' }
];
toggleLabel Function (node) => string Customize the aria-label of each expand/collapse toggle button. Receives the node object and must return a string. 
document.querySelector('au-tree').toggleLabel = (node) => {
  return `Expand or collapse ${node.label}`;
};
show-checkbox (attribute) boolean attribute When present, renders checkboxes on each node and enables tri-state (indeterminate) selection.
data-text-node (attribute) string Fallback node label when a node object does not provide label.
data-text-toggle (attribute) string template Accessible label template for expand/collapse buttons. Supports {label}.

Events

Tab enters the tree at its retained focus position; Up/Down move through visible nodes, Right expands or enters children, and Left collapses or moves to the parent in LTR. In RTL these two horizontal keys are mirrored. Clicking a row or activating its treeitem checks it in checkbox mode; the disclosure button only expands. Home/End move to the endpoints. Type a name prefix to find a visible node; * expands its siblings. Space checks an enabled node in checkbox mode. Tab leaves the tree.

Checkbox changes emit one event with all fully checked records. Disabled child branches are excluded when computing a parent's mixed state. Changing data or translations is silent. Original data objects are not mutated and this component does not submit native form values. Optional leaf checked and branch expanded data fields are reapplied on data assignment; omit them to retain interaction state. Optional lang sets each node's language.

Events dispatched by <au-tree>:
Event Detail Description
change { checkedNodes: node[] } Fired when a checkbox selection changes. checkedNodes is the array of all fully-checked node objects. Bubbles and is composed. 
document.querySelector('au-tree').addEventListener('change', (e) => {
  console.log('Checked nodes:', e.detail.checkedNodes);
});

// Vue
// <au-tree @change="onTreeChange">

// Angular
// <au-tree (change)="onTreeChange($event)">
