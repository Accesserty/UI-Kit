Attributes

The Accesserty UI Kit file upload attributes:
Name Description
label Visible label for the file upload control.
accept Accepted file types, forwarded to the native file input.
multiple Allows adding more than one file. Without it, at most one file is accepted; remove it before choosing a replacement.
max-files Maximum retained file count (default 5). Nonnegative finite values are rounded down; zero accepts none. Invalid values use the default. Lowering limits does not delete existing files.
max-size-mb Maximum size per file in MB (default 5); nonnegative finite number. Invalid values use the default.
max-total-size-mb Maximum total selected size in MB (default 20). A batch exceeding this total is not added.
msg-drop-text Drag-and-drop area text.
msg-remove-text Visible text for each remove button.
msg-remove-file-label Accessible name template for each remove button. Supports {fileName} and {action} (the visible remove text). Defaults to {action} {fileName}. If a custom template omits the visible text, the component prepends it for speech-input matching. Localize both attributes together for natural wording.
msg-added Live region message when files are added. Supports {count}.
msg-removed Live region message when a file is removed. Supports {fileName}.
msg-required Validation message shown when the component is required but empty.
msg-type-error File type error message. Supports either a legacy suffix or a template with {fileName}.
msg-size-error File size error message. Supports either a legacy suffix or a template with {fileName} and {maxSize}.
msg-count-error File count error message. Supports either a legacy suffix or a template with {fileName} and {maxFiles}.
msg-total-size-error Total file size error message. Supports either a legacy prefix or a template with {maxTotalSize}.

  msg-drop-text="將檔案拖曳到這裡"

  msg-removed="已移除 {fileName}"
  msg-required="請至少上傳一個檔案"
  msg-type-error="{fileName} 的檔案格式不支援"
  msg-size-error="{fileName} 超過 {maxSize}MB"
  msg-count-error="{fileName} 無法新增，最多只能上傳 {maxFiles} 個檔案"
  msg-total-size-error="檔案總大小不可超過 {maxTotalSize}MB">
</au-file-upload>

Provide a named native <button type="button" slot="trigger"> to customize keyboard file selection, or omit the slot to use the default button. Public focus(options) focuses the visible trigger without opening the picker, and is ignored while effectively disabled. Host aria-describedby connects external text to the component's groups and default button, in addition to internal upload instructions. If you supply a custom trigger, set its own aria-describedby to your error/hint IDs; the component does not overwrite consumer ARIA. After the last focused remove button is removed, focus returns to an available trigger, or the visible trigger region if no usable trigger exists. A disabled component or ancestor fieldset prevents selection, dropping and removal without losing the selected files. Form validation focuses a visible region and displays the required message beside the picker.

Properties

JavaScript properties on <au-file-upload>:
Property Type Description
value File[] (getter + setter) Get a copy of the selected File array. Assigning an array copies valid File entries, replaces the list and synchronizes native form submission silently. Mutating the returned array does not update the component. Pre-registration assignments are retained. This controlled setter bypasses picker restrictions; use handleFiles(files) for accept/count/size validation. Client-side checks do not replace server validation. 
const fu = document.querySelector('au-file-upload');
console.log(fu.value); // File[]
fu.value = []; // clear files programmatically

Events

A named component contributes one real File entry per selected file to new FormData(form), under the component's current name. Empty or unnamed controls contribute no entries. Reset clears the submitted files. For native uploads use enctype="multipart/form-data"; when sending FormData with fetch, let the browser set the multipart Content-Type boundary. The component does not upload anything itself; enforce file-type and size checks on the server.

Events dispatched by <au-file-upload>:
Event Detail Description
change — Fired when files are accepted by handleFiles() or removed by the button or removeFile(file). Bubbles and is composed. Use el.value to read the current file list. Assigning value or resetting the form does not emit change.
remove-file File Fired once for an actual removal, through either the button or removeFile(file), before change. e.detail is the removed File object. Bubbles and is composed. Removing an absent file does nothing. 
const fu = document.querySelector('au-file-upload');

fu.addEventListener('change', () => {
  console.log('Files:', fu.value.map(f => f.name));
});

fu.addEventListener('remove-file', (e) => {
  console.log('Removed:', e.detail.name);
});
