Accesserty UI Kit Button

Use a native button

Use <button> for button behavior. UI Kit styles the native element rather than adding a custom button element.

Change its appearance with CSS. A custom element would add attribute handling, events and tests without helping when styling is the only requirement.

The patterned examples below explore a distinction that does not rely on color alone. Their usability has not been tested. Check readability and visual comfort before using a pattern; it is not an accessibility guarantee.
