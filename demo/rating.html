Accesserty UI Kit Rating

How to use

HTML

  1. Copy file (rating.js or accesserty-ui-kit.js)
  2. Add the JavaScript file to HTML using the <script src="" defer> tag
  3. Use the <au-rating> tag

Attributes

Attribute Description Default
name Form field name; required for submission. Also writable as a JavaScript property. Empty (not submitted)
max Maximum score (positive integer number of stars, capped at 100). Invalid values use 5. Also writable as a JavaScript property. 5
value Current score, clamped to 0–max. Invalid numbers become 0. Zero and fractional scores do not check an integer radio. 0
labels Comma-separated labels for each level -
aria-label Accessible label for the group Rating
data-text-rating Fallback accessible label for the group when aria-label is not set. Rating
data-text-star Accessible label template for each score option when labels is not set. Supports {value} and {max}. {value} Star(s)
data-text-score Score description, visible when show-score is set and visually hidden otherwise. Supports {value}, {max}, and {scoreInfo}. Keep the numeric value in translated templates. {value} / {max} {scoreInfo}
score-info Additional text displayed after the score -
show-score Display "value / max" text next to stars -
disabled Disable all interaction false
readonly Display-only score. Radios are disabled and leave the Tab order; the group and exact score remain available to assistive technology. A named readonly score is still submitted. false

Properties

JavaScript properties on <au-rating>:
Property Type Description
namestring (getter + setter)Reflects the form field name; changing it changes the submission key.
maxnumber (getter + setter)Changes the number of options and recomputes the bounded score.
value number (getter + setter) Get or set the current rating value programmatically. Accepts decimals for partial stars.
disabled boolean (getter + setter) Get or set the disabled state.
readonly boolean (getter + setter) Get or set the display-only state. Internal radios cannot be focused or changed. 
const rating = document.querySelector('au-rating');
rating.value = 3.5;    // set partial star
console.log(rating.value); // 3.5
rating.readonly = true;

Left/Right follow visual direction in RTL; Up/Down keep decrement/increment behavior. Partial stars fill from the inline start edge. Integer values synchronize the selected radio, star fill, score text and form value. Fractional values keep partial stars and the exact score description, without selecting a rounded integer. User interaction chooses integer values. Reset restores the value captured when the element first connects, bounded by the current max; property updates and reset do not emit change. Label updates preserve existing option nodes and focus.

element.focus({ preventScroll: true }) focuses the current enabled radio without selecting it. Disabled and readonly ratings ignore focus requests. Host aria-invalid is mirrored to the radiogroup. Use aria-describedby on the host to reference external error or hint text; it is combined with the internal score description and follows text replacement and updates. Application-specific constraint validation remains the consumer's responsibility.

Event Listeners

The <au-rating> component dispatches a change event when the rating is changed by the user. The event bubbles across Shadow DOM and carries detail.value. Reconnecting the same element does not add duplicate handlers.

document.querySelector('au-rating').addEventListener('change', (e) => { console.log('Selected rating:', e.detail.value); });

Accessibility

  • Native radio options; the host submits through ElementInternals.
  • Tab enters one option; Space selects it; arrow keys move and select with wrapping, following the APG rating keyboard pattern.
  • Named radiogroup with an exact score description; these semantics are not a substitute for screen-reader testing.
  • Visible labels below each star for clarity
  • Focus indication with visible ring
  • Use readonly for display-only scores; disabled (including a disabled ancestor fieldset) also excludes the value from native submission.
  • Reduced-motion and forced-colors styles, wrapping layout and a non-color-only selected marker. Recheck contrast and target sizes when customizing the theme.
