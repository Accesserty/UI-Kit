Card contract

Card is a layout primitive, not a button, landmark or form control. It adds no host role, tabindex, custom event or automatic heading semantics. Native child controls keep their form, focus and event behavior. The sample images are decorative, and Save example only toggles local state in this demo.

Use heading, media, content and footer slots. There is no default slot: unassigned content is not projected. CSS Parts identify the container and slot elements; style actual light-DOM content using your own selectors. Repeated render calls keep the existing slot structure. The hidden attribute hides the card.

For SSR, register only on the client. Next, Nuxt and Angular fixtures preserve server-produced hosts and content nodes while creating the internal slots in the browser. Browser tests are not VoiceOver or full WCAG verification.
