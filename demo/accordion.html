How to use

  1. Copy dist/components/accordion.js or its minified file for this component only. Use a full bundle from dist/ if you need all components.
  2. Load the copied file with a <script src="" defer> tag
  3. Place <au-accordion-item> elements directly inside <au-accordion>.

Set the script's src to the copied file's location. Use the built files, not an individual source file, with a classic script tag.

Exclusive Mode

Add exclusive attribute to <au-accordion>. When one item opens, all others close automatically.

Only direct item children participate; nested groups are independent. Initialization, inserted items and enabling exclusive mode retain the first open direct item. All items may be closed. Enter/Space toggles a header; Tab/Shift+Tab follows the visible controls. Closing focused content returns focus to its header.

Custom Style

Style the first and last items

Select the au-accordion-item hosts with :first-child and :last-child.

Use ::part(button) and ::part(region) to style their internal header and panel. Ordinary page selectors cannot reach inside an item's Shadow DOM.

/* demo.css */ au-accordion-item { &::part(button) { border-bottom: 0; } &::part(region) { border-bottom: 0; } &:first-child { &::part(button){ border-radius: 0.25rem 0.25rem 0 0; } } &:last-child { &::part(button){ border-bottom: 1px solid oklch(0.7894 0 0); border-radius: 0 0 0.25rem 0.25rem; } &::part(region){ border-radius: 0 0 0.25rem 0.25rem; } } &[open] { &:last-child { &::part(button) { border-bottom: 0; border-radius: 0; } &::part(region) { border-bottom: 1px solid oklch(0.7894 0 0); } } } }

Attributes & Properties

<au-accordion>

Attribute / Property Type Default Description
exclusive boolean false When present, only one item can be open at a time. Opening an item closes all siblings.

<au-accordion-item>

Attribute / Property Type Default Description
open boolean false Controls the expanded state. Settable via attribute or JS property (element.open = true).
heading-levelinteger attribute, 1–63Heading level surrounding the native button. Choose a level appropriate to the page outline; invalid values fall back to 3.
no-regionboolean attributefalseOmits the panel landmark role. Use when many simultaneously open panels would create too many regions; visibility and keyboard behavior remain unchanged.

Events

Event Dispatched from Bubbles Composed detail Description
au-toggle <au-accordion-item> true true { open: boolean } Fires for each actual connected open-state change, including programmatic changes and exclusive sibling closures. Same-value writes do not repeat events. Group listeners should filter the originating item to avoid treating nested events as their own.

Framework usage examples

<!-- Vue --> <au-accordion-item @au-toggle="onToggle">...</au-accordion-item> <!-- Vanilla JS --> document.querySelector('au-accordion-item').addEventListener('au-toggle', (e) => { console.log(e.detail.open); // true | false });

Integration limits

Panels show and hide immediately. Collapsed content stays out of the Tab order and accessibility tree; where the browser supports hidden="until-found", find-in-page and links into it open the panel, otherwise it is hidden and inert. Header and icon transitions respect reduced-motion preferences. Focus outlines remain visible in forced-colors mode.

With the kit's declarative Shadow DOM injector, the server inserts the accordion's internal markup. Items appear open or collapsed before JavaScript runs. The component then adopts that markup. Without the injector, the server renders only the host and slotted content; the browser creates the internal controls. See Server rendering in the README for setup and framework limits.

Test your content, theme and screen-reader interaction in your application. Using this component does not guarantee WCAG conformance.
