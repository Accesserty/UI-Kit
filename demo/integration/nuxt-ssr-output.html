au-carousel × Nuxt SSR — hydration i18n

This page is exactly what a Nuxt server would send: the <au-carousel> tag with its i18n data-* attributes and slide content already rendered as HTML text (the server never runs the web component). The component script is loaded client-only at the end — as you would from a Nuxt *.client.ts plugin — because the bundle extends HTMLElement and cannot be imported on the Node server. On upgrade it reads the localized attributes.
