# Security policy

## Supported versions

Security fixes are made for the latest 3.x release. Older releases do not
receive fixes; upgrade with [UPGRADING.md](UPGRADING.md).

## Report a vulnerability

Do not open a public issue for a security problem.

Email **service@accesserty.com** with:

- the affected component, file or integration (plain HTML, Vue/Nuxt,
  React/Next.js or the server-rendering helpers);
- the UI Kit version;
- steps or a small example that shows the problem, and its impact.

Please give us time to fix the problem before you disclose it publicly. We
will tell you when a fix is released and, if you want, credit you in the
release notes.

## Scope

This policy covers the code in this repository: the components, the
integration and server-rendering modules, and the build scripts. Security
problems in other Accesserty products or on accesserty.com follow
[accesserty.com/.well-known/security.txt](https://accesserty.com/.well-known/security.txt).

Accessibility problems are not security issues. Report them as described in
[ACCESSIBILITY.md](ACCESSIBILITY.md#report-a-barrier).
