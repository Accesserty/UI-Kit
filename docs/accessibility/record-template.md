## Findings and retest

For each finding, record affected users, reproduction, actual versus expected
behavior, environment, severity rationale, source/issue link and fix revision.
Retest in a new dated record; preserve the original failure.

## Automated evidence (separate)

output. A successful build or script is not a manual/screen-reader pass.
