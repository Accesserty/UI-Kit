# Documentation map

Start with the document for your task. You do not need to read the design history
to use a component.

## Current guides

| I want to… | Read |
|---|---|
| Load the kit in HTML or a framework | [Quick start and integration](../README.md) |
| Connect component state, forms and events | [Usage reference](USAGE.md) |
| Find a component's properties, events or CSS variables | [Component demos](../demo/index.html) |
| Upgrade an existing installation | [Upgrade guide](../UPGRADING.md) |
| Change the implementation or add a component | [Contribution guide](../CONTRIBUTING.md) and [architecture](ARCHITECTURE.md) |
| Run or inspect framework examples | [Integration examples](../demo/integration/README.md) |
| Check what the framework tests cover | [SSR test fixtures](../test/ssr/README.md) |

Use the guides from the same release as your copied files. A guide on `main` can
describe behavior that is not in an older downloaded bundle.

## Release records

Read [GitHub Releases](https://github.com/Accesserty/UI-Kit/releases) for changes
and verification notes recorded for each release. A release note describes that
version, not later fixes. Use the current guides above for supported APIs and
setup instructions, or select the matching release tag when using an older copy.
